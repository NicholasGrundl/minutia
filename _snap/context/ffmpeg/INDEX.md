# FFmpeg Context Index

This directory provides a curated technical reference for building audio/video processing pipelines using FFmpeg and FFprobe.

## 1. Core CLI Tools
- **[ffmpeg-tool.md](./ffmpeg-tool.md)**: Primary reference for the `ffmpeg` command, including stream selection (`-map`), global flags, and codec-specific options.
- **[ffprobe-tool.md](./ffprobe-tool.md)**: Guide for analyzing media stream metadata, including JSON output formatting for automated pipelines.

## 2. Components & Protocols
- **[ffmpeg-filters-protocols.md](./ffmpeg-filters-protocols.md)**: Reference for filtergraph syntax and common audio/video filters (scale, crop, resample, merge), plus supported I/O protocols (file, pipe, http).

## 3. External Sources
- **[RESOURCES.md](./RESOURCES.md)**: Original documentation links and ingestion status for these synthesized guides.
