# Intro to Claude
Claude is a highly performant, trustworthy, and intelligent AI platform built by Anthropic. Claude excels at tasks involving language, reasoning, analysis, coding, and more.

The latest generation of Claude models includes:
*   **Claude Opus 4.6** - Described as Anthropic's most intelligent model, excelling in coding, enterprise agents, and professional work.
*   **Claude Sonnet 4.6** - Offers frontier intelligence at scale, built for coding, agents, and enterprise workflows.
*   **Claude Haiku 4.5** - The fastest model with near-frontier intelligence.

You can chat with Claude by visiting claude.ai.

### Get started
If you are new to Claude, you can learn the essentials and make your first API call by setting up your development environment. You can also learn about the family of Claude models and explore example prompts for inspiration.

### Develop with Claude
Anthropic provides developer tools for building scalable applications with Claude, including:
*   **Developer Console** - Features a Workbench and prompt generator tool for easier and more powerful prompting in your browser.
*   **API Reference** - Allows you to explore, implement, and scale with the Claude API and SDKs.
*   **Claude Cookbook** - Offers interactive Jupyter notebooks to demonstrate tasks like uploading PDFs and embeddings.

### Key capabilities
Claude can assist with various tasks involving text, code, and images:
*   **Text and code generation** - Can summarize text, answer questions, extract data, translate text, and explain and generate code.
*   **Vision** - Can process and analyze visual input, and generate text and code from images.
