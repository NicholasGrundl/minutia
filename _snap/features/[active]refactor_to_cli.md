# Refactor to Production CLI (v0.2.0)

## Executive Overview

Minutia is transitioning from a notebook-driven workflow (`CreateTranscriptProd.ipynb`) plus a
standalone `baseline_pipeline.py` script into a proper `src/minutia/` package: `RunPaths`-based
path management, a `PipelineOrchestrator`, one module per pipeline stage under `steps/`, and a
Click CLI. Testing follows a "Golden Sample" methodology — fixtures with known-good outputs
generated from the trusted legacy notebook live in `tests/fixtures/scenarios/`, and refactored
logic is validated against them.

**Non-goals** (for this spec): rich CLI progress UI, resume-from-failure, local LLM
summarization, SQL-backed job tracking. Those belong to the broader post-refactor vision — see
[`[draft]refactor_for_opensource_portfolio.md`](./%5Bdraft%5Drefactor_for_opensource_portfolio.md).

## Details

**Target architecture** (from the former `refactor-architecture-spec.md`):
```
src/minutia/
├── cli.py / config.py / logging.py / paths.py
├── legacy/          # isolated Jupyter-era code
├── pipeline/orchestrator.py
└── steps/{video_extraction,audio_transcription,transcript_merger,summarize_transcript}.py
```

**Testing** follows the Golden Sample standard (former `refactor-testing-guide.md`): fixtures
in `tests/fixtures/scenarios/{scenario}/{01_extracted,02_transcribed,03_merged,04_summarized}/`
generated by the trusted legacy notebook; integration tests assert refactored-step output
matches. Generator script: `tests/scripts/generate_golden_samples.py`.
