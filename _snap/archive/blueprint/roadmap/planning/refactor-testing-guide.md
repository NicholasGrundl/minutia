# Refactor Testing Guide: The Golden Sample Standard

## Overview
This guide defines the testing strategy for the Minutia refactor. We follow a strict **"Golden Sample"** methodology: we do not guess if code works; we prove it matches the known-good outputs from the original notebook.

## 1. The "Golden Sample" Philosophy
A "Golden Sample" is a set of artifacts (inputs and expected outputs) generated by the trusted legacy system (`CreateTranscriptProd.ipynb`).

**Location:** `tests/fixtures/scenarios/{scenario_name}/`
*   `input.mkv`: The raw source.
*   `01_extracted/`: Expected WAV files.
*   `02_transcribed/`: Expected Whisper JSON (structure matters, text may vary slightly).
*   `03_merged/`: Expected Merged JSON (Crucial for overlap logic).
*   `04_summarized/`: Expected Summary (Crucial for prompt logic).

## 2. Generating Golden Samples
**Do not create fixtures manually.** Use the generator script.

```bash
# Generate artifacts for all defined scenarios
python tests/scripts/generate_golden_samples.py
```

*Prerequisite*: You must have `ffmpeg` installed and a valid `ANTHROPIC_API_KEY` env var.

## 3. Writing Integration Tests (The Refactor Validator)
Integration tests live in `tests/integration/` and validate specific **steps**.

**Pattern:**
1.  **Arrange**: Load the `input` and `expected output` from a scenario fixture.
2.  **Act**: Run the refactored step (e.g., `process_transcripts`).
3.  **Assert**: Compare the `actual output` file content with the `expected output`.

**Example: Testing the Merger**
```python
def test_merge_logic_matches_golden(tmp_path):
    # Arrange
    scenario = Path("tests/fixtures/scenarios/microphone_only")
    mic_json = scenario / "02_transcribed/microphone.json"
    desk_json = scenario / "02_transcribed/desktop.json"
    expected_merged = json.loads((scenario / "03_merged/merged.json").read_text())

    # Act
    output_file = tmp_path / "merged.json"
    transcript_merger.process_transcripts(mic_json, desk_json, output_file)

    # Assert
    actual = json.loads(output_file.read_text())
    assert actual["metadata"]["segment_count"] == expected_merged["metadata"]["segment_count"]
    # Deep compare segments...
```

## 4. Writing Slow Tests (End-to-End Regression)
Slow tests live in `tests/slow/` and run the full `PipelineOrchestrator`.

**Goal**: Ensure the wired-up system produces the final summary.

```bash
# Run only slow tests
pytest tests/slow/
```

## 5. Development Workflow (TDD)
1.  **Pick a Task** (e.g., "Port Overlap Logic").
2.  **Run the Test**: `pytest tests/integration/test_merger.py`.
    *   *Result*: **FAIL** (because logic is missing).
3.  **Implement**: Copy logic from `baseline_pipeline.py` or notebook to `transcript_merger.py`.
4.  **Run the Test**: `pytest tests/integration/test_merger.py`.
    *   *Result*: **PASS**.
5.  **Commit**: "feat: port overlap logic (verified against golden sample)".
